# Мебель для Жизни — редизайн v8 (Hotel Lobby поверх живого сайта)

В отличие от v1–v7, здесь **полностью сохранена структура и React-приложение текущего сайта** abdublinn.github.io. Меняется только тема: палитра + шрифты + границы, через override-таблицу `theme-override.css`.

**Что осталось из оригинала:**
- Все секции, элементы, кнопки, формы
- Все фотографии
- Вся динамика, анимации, интерактив (квиз, карусель проектов, прямая трансляция)
- Структура и порядок блоков

**Что заменилось:**
- Палитра: лесной зелёный + слоновая кость + шампань (v7 Hotel Lobby)
- Шрифты: Wix Madefor Display + Golos Text → **Cormorant Garamond + Inter**
- Brand-оранжевый `#E8501A` → шампань `#C9A96E`
- Кремовые блоки → forest surface

**Live:** https://abdublinn.github.io/mebel-redesign-v8-hotel-on-original/
